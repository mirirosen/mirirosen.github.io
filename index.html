הורדת המתקין דרך GitHub בלבד · ללא כרטיס אשראי

Windows עלול להציג אזהרה

זה נורמלי לאפליקציות חדשות. שלושה צעדים קצרים וההתקנה נמשכת:

1

לחצו על «מידע נוסף»

Windows SmartScreen מופיע לאפליקציות שעדיין לא נצבר להן מוניטין רחב. בתיבת האזהרה יש קישור קטן — זה המסלול הבטוח להמשיך.

2

לחצו על «הפעל בכל זאת»

אחרי שלב 1 מופיע כפתור הרצה. זה מאשר שאתם מודעים למקור הקובץ ומבקשים להמשיך.

3

B Notes מתקין את עצמו

בסיום ההתקנה Chrome ו‑Edge יזהו את התוסף בהפעלה הבאה של הדפדפן (בהתאם להגדרות המערכת).

שאלות על ההתקנה

תשובות קצרות לפני או אחרי ההורדה מ-GitHub.

כן. הקובץ מתפרסם רק דרך GitHub Releases והמתקין נועד להתקין את B Notes ואת התוסף כמתוכנן. האזהרה של Windows נפוצה אצל אפליקציות חדשות עד שנבנה מוניטין — ולא בהכרח מצביעה על בעיה אבטחתית.

כן. המתקין מגדיר את התוסף גם ל‑Chrome וגם ל‑Edge במחשבים שבהם מותקנים שניהם.

ב‑Windows: הגדרות ← אפליקציות ← התקנות אפליקציות, חיפוש «B Notes», ובחירה בהסרת התקנה. לאחר מכן כדאי לאמת בהגדרות התוספים בדפדפן שאין התקנה נותרת.
